# 전기기능사 제어판 시뮬레이터

전기기능사 실기 공개문제 1~18번의 제어판 배선을 연습하는 웹 시뮬레이터예요.

**바로 열기 → https://pasaeng1592-lang.github.io/panel-sim/**

## 할 수 있는 것

- 배선 · 벨시험 · 동작시험 · 채점
- 틀린 곳 점검, 정답 회로 보기 (주결선 · 보조결선 · 단자대별)
- 연습 타이머 (시험 시간 4시간 30분)
- 시퀀스 회로도 기록 (번호 찍기 · 펜 · 형광펜), 기구 내부 결선도 참고

## 알아 둘 점

- 컴퓨터, 아이패드, 휴대폰 브라우저에서 바로 열려요. 설치할 건 없어요.
- 배선 · 기록 · 타이머는 각자 쓰는 브라우저에만 저장돼요. 다른 사람과 공유되지 않아요.
